🔒 Usa un repositorio privado solo para los datos. Si es público, cualquiera podrá leerlos. El token se guarda en este dispositivo.
¿Cómo obtengo el token?
  1. Crea un repositorio privado en GitHub (p. ej. digimem-datos).
  2. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. En Repository access elige Only select repositories y marca ese repositorio.
  4. En Permissions → Repository pon Contents: Read and write.
  5. Copia el token y pégalo aquí.
